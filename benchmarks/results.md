# Barcode-ID Benchmark Results: Rust vs Java

Results are appended to this file by `tests/bench_vs_java.sh`.

## Methodology

- **Input**: N synthetic read pairs generated by `tests/gen_test_fastq.py`.
  All R2 reads contain exact barcode matches for the production layout
  `Y|SPACER|EVEN|SPACER|ODD|SPACER|EVEN|SPACER|ODD|SPACER|DPM` (125 bp).
  R1 is a fixed 50-bp random sequence (READ1 layout absent in production config).
- **Java**: `BarcodeIdentification_v1.2.0.jar` via `java -jar`.
- **Rust (1 thread)**: `barcode_id` release binary with `--threads 1`.
- **Rust (N threads)**: `barcode_id` release binary with `--threads N`
  (all CPUs unless `--threads` is passed to the bench script).
- **Correctness check**: `diff <(gzip -dc java_out1) <(gzip -dc rust1_out1)` —
  must produce no output (PASS) before results are recorded.
- **Wall time**: bash `time` builtin with `TIMEFORMAT='%R'`.
- **Throughput**: `reads / wall_time_seconds`.

To reproduce:
```bash
# 1. Build the Rust release binary
cd barcode_id && cargo build --release && cd ..

# 2. Run the benchmark (from project root)
chmod +x tests/bench_vs_java.sh
./tests/bench_vs_java.sh --n-reads 500000

# 3. Inspect results
cat benchmarks/results.md
```
